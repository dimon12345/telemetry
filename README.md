Telemetry project
=================

Collect over Wi-Fi and display data from IoT sensors

![pygui screenshot](https://github.com/dimon12345/telemetry_media/blob/master/screenshots/pygui.jpg)

Raspberry Pi OS (MQTT, PostgreSQL, tkinter + paho.mqtt.cpp, pqxx, CrowCpp)
Temperature sensor: ESP8266 + DHT11 (Arduino)
